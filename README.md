# Coffee-Sales-Dashboard (Excel)
An interactive Excel dashboard that visualizes coffee sales performance across different countries, products, and customers.

## Key Highlights
1. Analyzes total sales, profit, and top-performing coffee types.
2. Shows insights by country, roast type, and size.
3. Identifies top 5 customers and loyalty trends.
4. Built using PivotTables, PivotCharts, and slicers for interactivity.

## Data Sources
Orders, Products, and Customers sheets linked through a data model.
